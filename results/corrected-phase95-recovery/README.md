# Corrected Phase 95 aggregate results

These compact tables summarize the completed corrected 128-policy search described in `CORRECTED_SEARCH.md`. They contain the corrected historic benchmark, one row per endpoint policy, the ten-objective pass screen, family summaries, and task-completion status.

All 128 endpoint policies completed. Three passed all ten corrected screening criteria. The tables support search-level statements and candidate review; they do not designate a final paper policy and do not contain trained checkpoints or daily rollouts.

The `collection.json` paths were converted from the original compute-system paths to repository-relative names. Scientific values in the CSV and benchmark JSON files are unchanged. `SHA256SUMS` records the public copies.
