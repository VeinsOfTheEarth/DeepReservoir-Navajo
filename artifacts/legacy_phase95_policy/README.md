# Archived pre-correction Phase 95 policy

These files preserve the seed-004 checkpoint, evaluation, family summary, and perturbation results used by the current model-dependent figure exports. They are retained for provenance and regression checks.

The manuscript audit changed the flood reward location, hydropower tailwater curve, information timing, storage basis and normalization, irrigation fallback, spring-season handling, and related evaluation definitions. Because this checkpoint predates those changes, it is not eligible for final corrected-policy selection. The corrected recovery results are separate.

# Archived artifact contents

This directory contains the frozen policy and evaluation artifacts used for the
paper figures and tables.

- `navajo_reservoir_selected_policy.zip`: Stable-Baselines policy archive for
  the archived policy.
- `selected_policy_eval_metrics.json` and `selected_policy_eval_metrics.csv`:
  Frozen evaluation metrics for the archived policy over the 2014-01-01 to 2024-08-17
  holdout period.
- `selected_policy_eval_rollout.parquet`: Daily holdout rollout for the selected
  policy, used to build paper figures.
- `selected_policy_family_seed_metrics.csv`: Seed-level evaluation metrics for
  all 16 seeds in the selected family,
  `reward_jon_p95_peak875_hdisceff`. This snapshots the seed information needed
  for paper-release tables without requiring the ignored `runs/` directory.
- `initial_storage_sweep/`: Compact selected-policy stress artifact generated by
  `scripts/run_selected_policy_initial_storage_sweep.py`. This varies initial
  storage from 0 MAF to spill storage in 0.1 MAF increments and stores the
  storage trajectories plus summary metrics used for the paper figure.
- `inflow_scaling_sweep/`: Compact selected-policy stress artifact generated by
  `scripts/run_selected_policy_inflow_scaling_sweep.py`. This scales reservoir
  inflow from -50% to +150% relative to nominal in 10% increments and stores the
  storage trajectories plus summary metrics used for the paper figure.
