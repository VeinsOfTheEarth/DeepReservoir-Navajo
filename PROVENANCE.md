# Public snapshot provenance

This repository was assembled on September 23, 2026 as a fresh public history from the project's corrected recovery code. Private Git history, development worktrees, deleted presentations, local experiment directories, caches, and unrelated research material were not imported.

The snapshot includes the corrected physical environment and metrics, the completed corrected Phase 95 search workflow, and compact aggregate results from all 128 endpoint policies. Candidate checkpoints and daily rollouts from that search are not included because final policy selection remains pending.

The checkpoint under `artifacts/legacy_phase95_policy/` predates the manuscript-audit corrections. It is retained with its frozen metrics and figure inputs for provenance and regression checks. It is not the final corrected paper policy.

Appendix A--C packages were ported from the manuscript working repository, made repository-relative, and verified against their source exports. External reports and historical slide decks that are not runtime dependencies are linked or accepted as optional provenance inputs instead of being redistributed.

Detailed private branch and worktree history remains in the private manuscript handoff. Compact result tables retain their source commit identifiers where needed to bind reported values to the code that generated them.
