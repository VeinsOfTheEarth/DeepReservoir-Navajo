# SPR Flow

`spr-flow.pptx` is the author-confirmed editable source, renamed from
`spr_reward_diagram.pptx` without changing its contents.

- `spr-flow.pdf`: the retained paper export; preferred for Overleaf.
- `spr-flow.pptx`: the editable PowerPoint source.

The old PNG predates the latest PowerPoint/PDF and has been moved to
`.figure-archive/repo-extras-2026-09-08/paper/figures/spr-flow/`.
Use the PDF for the paper, or export a new PNG from PowerPoint when needed.
For revisions, edit the PowerPoint and export a new PDF from PowerPoint.
The final manually edited figure is not generated by a Python builder and
does not need additional experiment data.

The earlier Python prototypes, their component diagrams, the alternate
`spr-reward-flowchart.pdf`, and the old root-level screenshot were moved to
the ignored `.figure-archive/manual-source-cleanup/` folder. That archive is
not needed to use or edit this figure.
