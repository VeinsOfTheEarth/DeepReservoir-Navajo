# Historic Timeseries

Run `python -B paper/figures/historic-timeseries/build.py` from the repository
root. It writes `historic-timeseries.png` and `historic-timeseries.pdf`.
The local `common.py` retains the original period shading, data loading, and
styling helpers. Inputs are the repository's physical-environment observations
and selected-policy training/evaluation date definitions; no extra runs are needed.
