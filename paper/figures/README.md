# Paper figures

The programmatic result figures use corrected Phase 95 recovery task 105. Each figure directory contains its builder, compact inputs, exports, and source notes. The study-system map, objective-location schematic, and spring-release flowchart retain their manually edited PowerPoint/PDF sources.

Run `python paper/build-figures.py` from the repository root to rebuild the eleven programmatic main figures. Appendix packages have separate builders under `paper/figures/appendix/`.
